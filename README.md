UGREEN DXP2800 – Recursos técnicos

Este repositorio contiene los ficheros técnicos utilizados durante la revisión del NAS UGREEN DXP2800 GT publicada en PCDEMANO. Incluye la configuración real de Pi‑hole + Unbound en UGOS, datos y notebooks de análisis térmico, y documentación auxiliar.

Contenido
docker/pihole-unbound/  
docker-compose.yaml utilizado en la interfaz de UGOS para desplegar Pi‑hole y Unbound.
Nota: Este archivo se usa únicamente para copiarlo en la interfaz del NAS.

colab/  
Notebook de análisis CPU ↔ temperatura utilizado para evaluar el comportamiento térmico del NAS.

docs/  
Documentación técnica complementaria utilizada durante las pruebas.

data/  
Datos utilizados en las pruebas térmicas.

Nota
Este repositorio contiene únicamente los recursos técnicos.
La revisión completa, conclusiones y análisis se publican en PCDEMANO.
